# 三字符账号游戏准入回归

使用虚构账号、合成登录消息和内存队列，直接调用真实网关准入过程。不注册账号、不连接游戏、不访问数据库。

准备旧版和候选版的网关构建目录（包含其 DLL 依赖），从仓库根运行：

```sh
bash tests/gateway-login/run.sh old-gateway-bin candidate-gateway-bin
```

旧版负向对照应拒绝三字符账号、接受四字符账号。候选版应通过 32 项检查：账号和角色名长度边界、中文角色名、证书和版本字段、数据包大小、准确账号/角色/会话/套接字标识，以及仅一次登录转交入队。

ABI 检查核对公开类型和成员、程序集身份及依赖身份。它不能代替已授权的 Docker 与 PC 登录验收，也不能证明所有依赖的实现完全相同。正式部署仍需备份、维护锁和玩家退出检查；测试不授予任何运行权限。
