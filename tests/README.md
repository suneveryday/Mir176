# 独立项目回归源代码

这些离线回归覆盖网关、GM 精确回执、角色存档、外观及消息队列正确性。测试使用隔离夹具，不连接真实游戏。

测试结果必须在Mir2Classic176完整重建后重新记录；不继承来源项目的通过状态。各目录README说明输入和隔离要求，禁止把历史测试程序连接到真实玩家数据库或自动运行部署适配器。

本项目还需为2003内容目录、成长经济、技能、怪物生命周期、地图、PK/组队/城战及独立存档补充有意义的回归和Windows/Docker验收。GM与bot分别遵守其独立仓库门禁。

PC客户端源码、构建证据、资源清单与专项测试现由 [Mir176Client](https://github.com/suneveryday/Mir176Client) 维护；旧本地路径以迁移说明为准。
