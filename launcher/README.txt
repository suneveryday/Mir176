Mir176 经典版登录器 0.1.6（Windows）

本包只有登录器。完整客户端和资源由其他方式提供。

1. 将 Mir176Launcher.exe 放在完整客户端目录，与 Mir2Classic176.exe 同级。
2. 双击登录器，输入服务提供者给出的服务器 IPv4 地址或域名、登录端口。
3. 点击“开始游戏”，随后在游戏窗口输入账号和密码。

首次地址为空，默认登录端口7000可修改。以后会读取本机保存的设置。
改服务器前，请先正常退出游戏并完成保存。“保存设置”只保存，不启动游戏。
只修改本机 Mir2Classic176.ini 中的 Address/Port，保留画面和资源等原有设置内容。
无BOM按CP936读取，CP936/UTF-16LE保留编码；UTF-8 BOM转为旧客户端可读的UTF-16LE。
登录器不保存游戏账号密码，不复制角色进度，也不启动服务端、GM或bot。

地址上限为30个ASCII字符；支持IPv4和域名，不支持IPv6字面量或网址。
需要Windows .NET Framework 4.x；Windows 10/11通常已自带。
配套游戏客户端0.1.5、Docker服务端0.1.4，无协议或存档迁移。

服务端管理员仍须配置玩家可达的登录、选角及游戏网关地址/端口。
登录器不能修正服务端发错的跳转地址，也不能代替路由与防火墙设置。
程序散列见 package-manifest.json；完整运行组合仍待验证。
